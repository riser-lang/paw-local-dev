## 界面要修的地方（P1：评委第一眼就会看到；并入 C-08 第一项）
1. **"需要你决定"卡片的标题**：现在是"是否批准：" + 原文摘录，出现了"推进至执行阶段。？"这种句号后面再跟问号的情况。改为：先用一句话说清要决定什么（例如"把这条进展写入【冲刺项目】？"），原文摘录另起一行显示。
2. **选"是"/选"否"会怎样**：三张卡片写的都是同一句通用话（"按所列提议的内容和操作写入正式工作区"）。需求要求写清**具体**后果，例如"选是：冲刺项目的'进度与里程碑'改为……；选否：保持现状"。按候选类型和目标栏目生成，不需要调用模型。
3. **"本地维护"区的时间**：显示的是 `2026-10-16T03:00:30.757197+00:00` 这种原始 UTC 时间。统一改为本地时间、短格式（例如"10/16 11:00"），与顶部系统状态一致。
4. **"影响中"标记**：意思不清楚。要么换成用户能看懂的词（例如"影响：中"），要么去掉。
5. 改完后，PM-C1 系列用例照常必须通过；在 DONE 中附上修改前后的截图对比。
