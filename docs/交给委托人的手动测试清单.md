# PAW Personal Work OS (Windows 本地化版) 手动测试指南
> 本指南专为**产品经理与非技术人员**量身编写。无需任何代码经验、不跑任何命令，完全按照普通用户日常操作步骤进行验收。

---

## 📋 测试前准备
- 一台 Windows 10 或 Windows 11 电脑（无需安装任何开发工具或运行库）；
- 准备一个包含日常办公文档的测试文件夹（建议包含几个 Word、Excel 表格、PPT 幻灯片与 PDF 文档）；
- 准备一个文本文件，故意将其扩展名改为 `.docx`（用于模拟损坏的办公文档）。

---

## 🧪 手动验收测试用例

### 用例 1：全新安装与首次引导（开箱体验）
- [ ] **步骤 1.1**：在电脑上找到安装包 `PAW_Personal_Work_OS_Setup_v2.3.2.exe`，直接双击运行。
  - *预期看到*：弹出标准的 Windows 软件安装向导窗口，包含软件许可说明与安装路径选择。
- [ ] **步骤 1.2**：点击「下一步」，保持勾选「创建桌面快捷方式」，点击「安装」。
  - *预期看到*：进度条平稳推进，数秒内完成安装。
- [ ] **步骤 1.3**：保持勾选启动程序选项，点击「完成」。
  - *预期看到*：系统自动启动并自动打开您的默认浏览器（http://127.0.0.1:8800/app），展现 PAW 个人 AI 工作台主界面，桌面出现 PAW 图标。
- [ ] **步骤 1.4**：观察工作台右下角自动弹出的新手引导对话框（标题为「欢迎使用 PAW Personal Work OS (Windows 本地化版)」）：
  - *预期看到*：可配置本地工作文件夹，可选择 AI 模型服务（提供 DeepSeek、通义千问、OpenAI、离线模式等模板）。
- [ ] **步骤 1.5**：选择本地工作文件夹后，点击「检查此目录」。
  - *预期看到*：下方显示预检统计，列出发现的可解析办公文档数量与预计首次解析耗时。
- [ ] **步骤 1.6**：点击「完成引导，开启 PAW 守护」。
  - *预期看到*：弹出成功提示，自动切换至「文件夹扫描」面板。

---

### 用例 2：首次文件夹扫描与进度体验（平滑不卡顿）
- [ ] **步骤 2.1**：在控制台「文件夹扫描」页面，点击「开始全量扫描」。
  - *预期看到*：
    - 进度条平稳前进，实时显示处理进度与百分比；
    - 「当前处理」清晰显示正在解析的具体文件名；
    - 「已用时间」与预计剩余时间实时呈现。
- [ ] **步骤 2.2**：扫描过程中点击「暂停扫描」。
  - *预期看到*：状态立刻切换为「扫描已暂停」，此时打开电脑的 Word 或 Excel 处理其他工作，电脑完全无卡顿感。
- [ ] **步骤 2.3**：点击「继续扫描」。
  - *预期看到*：扫描状态立刻恢复，进度紧接着暂停点继续向下处理，未重新从头扫描。
- [ ] **步骤 2.4**：在扫描进行中，直接关闭浏览器或重启电脑，再次双击桌面图标打开 PAW。
  - *预期看到*：重新打开后直接继承之前的扫描记录（断点续扫），已处理的文件不会重复处理。

---

### 用例 3：异常与损坏文件非阻塞处理（绝不弹窗打断）
- [ ] **步骤 3.1**：在工作文件夹中放入一个损坏的假 Word 文档（如前文准备的文本改名文件）。
- [ ] **步骤 3.2**：让 PAW 进行扫描。
  - *预期看到*：PAW **绝不弹出任何报错弹窗**，扫描过程畅通无阻，自动跳过该文件继续处理后续文档。
- [ ] **步骤 3.3**：在扫描面板下方展开「跳过与解析异常清单」。
  - *预期看到*：列表中清晰登记了该损坏文件的名字，并展示具体错误原因与处理建议。
- [ ] **步骤 3.4**：点击该文件右侧的「重试」按钮。
  - *预期看到*：系统对单文件发起重试尝试，不影响其余任务。

---

### 用例 4：智能批量审核与正式资产沉淀（Human Governed）
- [ ] **步骤 4.1**：扫描完成后，切换至「批量审核」标签页。
  - *预期看到*：所有提炼出的待办与知识按「项目」与「主题」整齐归类呈现，条目右侧标有高置信度推荐标签。
- [ ] **步骤 4.2**：点击「勾选高置信度」或顶部的「全选所有条目」，然后点击「批量核准入库」按钮。
  - *预期看到*：弹出确认对话框，确认后系统提示批量审核完成及入库成功条数。
- [ ] **步骤 4.3**：回到 PAW 主工作台，依次点击左侧或顶部的「今日」、「项目」、「知识库」、「待办」。
  - *预期看到*：刚刚通过的条目完整显示在各个模块中，有条不紊，形成完整的个人工作脉络！

---

### 用例 5：日常办公文件新增自动巡航
- [ ] **步骤 5.1**：在日常工作文件夹中，新建并保存一份 Word 文档（例如写上一段周报或项目总结）。
- [ ] **步骤 5.2**：等待数秒后，打开控制台的「巡航与快照」或「批量审核」。
  - *预期看到*：PAW 自动感知到了文件的保存并完成分析，新生成的建议出现在审核清单中，无需手动上传或重新全盘扫描。

---

### 用例 6：模型连通性测试与人话报错
- [ ] **步骤 6.1**：进入控制台「系统状态」标签页或模型配置区域。
- [ ] **步骤 6.2**：在 API Key 中故意输入一段错误的无意义字符，点击「测试当前模型连通性」。
  - *预期看到*：下方出现错误提示，清晰显示错误类型与指导信息，而非生硬的代码堆栈。
- [ ] **步骤 6.3**：输入正确的有效 API Key，点击「测试当前模型连通性」。
  - *预期看到*：下方出现提示反馈测试通过并显示响应延迟，配置即刻生效。

---

### 用例 7：软件升级与卸载（数据零丢失保障）
- [ ] **步骤 7.1**：进入 Windows「设置」->「应用」中的已安装应用列表，找到「PAW Personal Work OS」，点击「卸载」。
- [ ] **步骤 7.2**：观察弹出的卸载确认对话框。
  - *预期看到*：向导明确弹窗询问：「是否同时删除 PAW 工作数据？」，且默认聚焦在「否」（保留）。
- [ ] **步骤 7.3**：点击「否」，等待卸载完成。
- [ ] **步骤 7.4**：再次运行 `PAW_Personal_Work_OS_Setup_v2.3.2.exe` 重新安装并打开。
  - *预期看到*：之前审核沉淀的所有知识库、项目与待办条目**完好无损全部保留**！绝不因软件升级或重装导致知识资产丢失。

---

### 用例 8：AI 助手 (Web Agy V2) 问答与证据引用检验（Evidence Gate）
- [ ] **步骤 8.1**：在主界面点击「AI助手」标签页，或点击右下角悬浮球。
  - *预期看到*：展示个人 AI 工作助理界面，包含会话交互区与状态提示。
- [ ] **步骤 8.2**：向助手提问已核准项目的核心目标与知识。
  - *预期看到*：
    - 助手精准作答，内容紧扣知识库真实内容；
    - 回答下方清晰展示引用的证据与知识依据，标明证据编号、来源文件与定位段落；
    - 绝无任何凭空编造的虚假引用（通过 Evidence Gate 强校验）。
- [ ] **步骤 8.3**：提问知识库中不存在的内容（如火星基地发射计划）。
  - *预期看到*：助手严谨提示未检索到相关证据或未确定项目，绝不胡乱捏造虚假信息。
- [ ] **步骤 8.4**：尝试输入诱导修改或删表指令。
  - *预期看到*：助手受到 Passive Data 隔离与只读边界保护，明确回复无法修改正式数据库，底座核心数据表无任何变更。
- [ ] **步骤 8.5**：断开网络或将 API Key 清空，再次向助手提问。
  - *预期看到*：系统自动平滑降级为纯离线检索模式，回答顶部醒目标注「【当前未使用 AI，仅显示检索到的内容】」，并直接列出本地匹配到的事实要点。

---

### 用例 9：数据库自动安全快照与一键灾难恢复（Disaster Recovery）
- [ ] **步骤 9.1**：进入控制台「巡航与快照」标签页，查看数据库自动备份与快照区域。
  - *预期看到*：列表中展示系统的自动快照清单（系统每日及批量核准前自动触发）。
- [ ] **步骤 9.2**：点击「+ 立即创建安全快照」。
  - *预期看到*：系统迅速创建一份新的安全备份，列表中立刻增加一条当前时间的快照记录，耗时极短且不卡界面。
- [ ] **步骤 9.3**：点击任意历史备份条目对应的恢复功能。
  - *预期看到*：系统弹出确认提示，确认后完成原子化恢复，恢复后数据库完整性（PRAGMA integrity_check）完美如初，所有历史知识与项目完整还原。
