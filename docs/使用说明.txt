================================================================================
           PAW Personal Work OS 个人办公操作系统 - 简明使用说明
                              （版本 2.5.0）
================================================================================
本软件是一款完全运行在您电脑本机的 AI 个人办公助手。
不需要电脑知识，跟着本指南走一遍，5 分钟就能上手。

--------------------------------------------------------------------------------
一、软件安装（只需一次）
--------------------------------------------------------------------------------
1. 双击安装包：PAW_Personal_Work_OS_Setup_v2.5.0.exe。
2. 如弹出蓝色“Windows 已保护你的电脑”，这是未购买商业签名的通用提示：
   点【更多信息】，再点【仍要运行】即可。
3. 一路点【下一步】到【完成】。桌面和开始菜单会生成【PAW Personal Work OS】图标。

--------------------------------------------------------------------------------
二、第一次打开
--------------------------------------------------------------------------------
1. 双击桌面【PAW Personal Work OS】启动，浏览器会自动打开工作台。
2. 右下角任务栏托盘有 PAW 图标，双击可随时唤回工作台；右键菜单含
   【暂停 / 恢复巡航 (&C)】、【系统健康自检 (&D)】、【安全退出 (&X)】。
3. 左侧主导航：【驾驶舱】、【今天】、【项目】、【知识】、【资料】、【待办】、
   【日历】、【待我审核】、【AI助手】。网页右下角悬浮圆钮打开
   【PAW 本地控制中心】。
4. 点击【驾驶舱】，一页看全四块，右上角还有状态区：
   -【需要你决定】：拿不准、必须由您拍板的事都排在这里，
     例如资料该归到哪个项目、两个栏目结论互相矛盾。
   -【项目总览】：每个项目一条手绘甘特图，一眼看出做到哪、还剩多少。
   -【AI 建议】：带“AI 建议”标签的都是推断，仅供参考，不会自动执行。
   -【资料去向】：最近收到的随手记和文件归到了哪里。
   -【系统状态】：右上角红绿灯，显示巡航、扫描、备份、模型是否正常。

--------------------------------------------------------------------------------
三、填写 API Key（推荐，开启大模型解析）
--------------------------------------------------------------------------------
1. 点右下角悬浮钮打开【PAW 本地控制中心】，选【系统与模型】标签页。
2. 在【推理大脑 Provider 预设模板】里选服务商：
   【DeepSeek (推荐: 高性价比推理)】、【通义千问 Qwen (阿里云兼容服务)】、
   【OpenAI (标准端点)】、【自定义 OpenAI 兼容接口 / 网关】、
   【纯离线规则推理 (无需 API Key)】。
3. 在【API Key (DPAPI 加密存储)】粘贴 Key（形如 sk-...）。
4. 点【测试当前模型连通性】，成功后点【保存所有设置】。
★ 您的 Key 用 Windows DPAPI 加密存在本机，磁盘和日志里没有明文，
  只用于调用您选择的模型服务商。

--------------------------------------------------------------------------------
四、五分钟新手路线
--------------------------------------------------------------------------------
第一步：按第三节填好 Key，测试连通性成功后【保存所有设置】。
第二步：在【监控工作目录 (支持添加多个文件夹)】点【添加监控文件夹】，
   选中您放工作材料的文件夹；把一份 Word 文档复制进去；
   在【文件夹扫描】标签页点【开始全量扫描】。
   ★ 第一次扫描请等一两分钟，资料越多等得越久，扫描完成前别关程序。
第三步：打开【驾驶舱】，在【需要你决定】里读一条，看完依据后采纳或拒绝，
   处理完这条就从列表里消失。
第四步：进【项目】打开任一项目档案页，看各栏目结论及来源，点开可看这句话
   出自哪份资料；在刚写入的栏目旁点【撤销】，原结论就会恢复。
第五步：进【AI助手】问一个建议类问题，例如“这个项目后续怎么优化”。
   AI 会基于已有资料给建议，并标注是建议、不是已确定的事实。
   也可以点名文件问，例如“项目周报_v2.docx 里写了什么”。

--------------------------------------------------------------------------------
五、系统会自动做什么、什么一定交给你
--------------------------------------------------------------------------------
【系统自动做的】四类机械判断：
1. 资料出新版本，自动用新版替代旧版；旧版仍可查看、可撤销。
2. 新内容与已有结论一致，跳过，不重复写入。
3. 新内容是补充，自动写入对应栏目。
4. 两份资料互相矛盾，不猜，直接进冲突清单等您裁决。
【一定交给您决定的】新建项目、KPI 目标、政策口径、绩效评价、人员任免、
   比赛赛制这类用户专属结论，系统只生成候选，等您核准，绝不自动采纳。
【关于建议】AI 建议单独标注（带“AI 建议”标签、浅色底），不会当成事实。

--------------------------------------------------------------------------------
六、周报和指标
--------------------------------------------------------------------------------
1. 周报：项目档案页里有【项目周报】一节，列出本期进展、变化、风险和建议；
   【驾驶舱】里还有【跨项目对比与项目周报】，可横向比较多个项目。
2. 指标：【驾驶舱】里的【系统进化指标】按周记录待决定数、资料覆盖率、
   冲突数、知识缺口数、建议被采纳比例、积压量，并显示【周趋势】。
3. 没填 Key 时：周报“建议”部分会提示【需要填写 Key】，其余栏目照常生成。

--------------------------------------------------------------------------------
七、常见问题
--------------------------------------------------------------------------------
Q1 提示“端口 8800 已被占用”？
A1 无需担心。PAW 会自动顺延到 8801、8802 等端口，浏览器也会自动打开新端口。

Q2 杀毒软件提示拦截？
A2 本软件未购买商业数字证书，可能被误报。请选择允许运行或加入信任白名单。

Q3 数据存在哪里？
A3 全在本机 %LOCALAPPDATA%\PAW（例如 C:\Users\您的用户名\AppData\Local\PAW），
   含数据库 workspace.db、证据索引和历史备份。

Q4 卸载后数据会丢吗？
A4 不会。卸载只移除程序和快捷方式，%LOCALAPPDATA%\PAW 里的数据完整保留，
   重装即可继续用。

Q5 资料归错了项目怎么办？
A5 两个办法任选：① 在项目档案页该栏目旁点【撤销】；② 若该条还在
   【需要你决定】里，直接在里面改掉项目再确认。撤销不删资料，
   原始资料一直留在【资料】里可查。

Q6 为什么有的建议被删掉了？
A6 没有依据的句子会被自动去掉。系统逐句核对建议是否有资料支撑，
   没依据的那句移除，有依据的部分保留。这是防编造，不是故障。

Q7 资料会被上传或泄露吗？
A7 PAW 本地优先，解析、存储、审核都在您电脑上跑，没有自己的中心服务器。
   对外交互只有两种：
   1. 填了 Key：提问或解析时，必要的上下文片段会发送给您选的模型服务商；
   2. 免 Key 联网搜索：问题涉及“最新”“官网”“政策”“新闻”等时效信息，
      或本地资料不足时，会自动向必应（Bing）或 DuckDuckGo 检索，
      只发送您输入的提问词，不发送本地文档和数据库内容。
      不想联网就在提问里加“只看工作台”或“不要联网”。
