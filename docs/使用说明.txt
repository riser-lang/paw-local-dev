================================================================================
           PAW Personal Work OS 个人办公操作系统 - 简明使用说明
================================================================================
本软件是一款完全运行在您电脑本机的 AI 个人办公助手。
不需要复杂的电脑知识，只需跟随本指南，5 分钟即可轻松上手。

--------------------------------------------------------------------------------
一、软件安装（只需安装一次）
--------------------------------------------------------------------------------
1. 双击运行安装包：PAW_Personal_Work_OS_Setup_v2.3.9.exe。
2. 如果电脑弹出蓝色背景的“Windows 已保护你的电脑”提示：
   这是 Windows 对未购买商业签名的个人软件的通用安全提示。
   请点击文字中的【更多信息】，然后点击右下角的【仍要运行】按钮即可。
3. 一路点击【下一步】，直到点击【完成】。
4. 安装完成后，您的电脑上会自动创建以下图标：
   - 桌面快捷方式：【PAW Personal Work OS】
   - 开始菜单程序组：【PAW Personal Work OS】以及【卸载 PAW Personal Work OS】

--------------------------------------------------------------------------------
二、第一次打开与界面介绍
--------------------------------------------------------------------------------
1. 双击桌面的【PAW Personal Work OS】图标启动。
2. 程序启动后，系统会自动打开默认浏览器，进入工作台界面（http://127.0.0.1:8800/app）。
3. 电脑右下角任务栏托盘会显示 PAW 图标：
   - 双击托盘图标，或鼠标右键点击选择【打开工作台 (&O)】，可随时重新唤出工作台；
   - 托盘菜单还包含【暂停 / 恢复巡航 (&C)】、【系统健康自检 (&D)】以及【安全退出 (&X)】。
4. 工作台左侧主导航栏包含常用功能：
   【今天】、【项目】、【知识】、【资料】、【待办】、【日历】、【待我审核】与【AI助手】。
5. 网页右下角有一个常驻的悬浮圆钮，点击即可打开【PAW 本地控制中心】弹窗。

--------------------------------------------------------------------------------
三、填写您的 API Key（推荐，开启大模型智能解析）
--------------------------------------------------------------------------------
如果您希望使用云端大模型帮您分析提炼，请配置您的 API Key：
1. 点击网页右下角悬浮按钮打开【PAW 本地控制中心】，选择【系统与模型】标签页。
2. 在【推理大脑 Provider 预设模板】下拉框中，选择您使用的服务商：
   - 【DeepSeek (推荐: 高性价比推理)】：官方深度求索接口（默认模型 deepseek-chat）
   - 【通义千问 Qwen (阿里云兼容服务)】：阿里百炼兼容接口（默认模型 qwen-plus）
   - 【OpenAI (标准端点)】：标准端点（默认模型 gpt-4o）
   - 【自定义 OpenAI 兼容接口 / 网关】：支持本地模型（如 Ollama）或第三方兼容接口
   - 【纯离线规则推理 (无需 API Key)】：无需 Key，完全依赖本地内置规则
3. 在【API Key (DPAPI 加密存储)】输入框中粘贴您的 Key（形如 sk-...）。
4. 点击【测试当前模型连通性】，显示成功后点击【保存所有设置】。
★ 安全说明：您的 API Key 在本地使用 Windows DPAPI 加密存储，磁盘与日志中不存储明文，
  只用于调用你选择的模型服务商。

--------------------------------------------------------------------------------
四、五分钟新手体验路线
--------------------------------------------------------------------------------
第一步【填写模型 API Key】：
  先按第三节指引，在控制中心【系统与模型】标签页中填入您的 API Key（如 DeepSeek、
  通义千问等），测试连通性成功后点击【保存所有设置】。
第二步【添加监控文件夹】：
  在控制中心【系统与模型】标签页中，找到【监控工作目录 (支持添加多个文件夹)】，
  点击【添加监控文件夹】按钮，选中您平时存放工作材料的文件夹（例如存有 Word 文档的目录）。
第三步【放入文档并开始全量扫描】：
  将一份写好的 Word 工作周报或汇报文档（.docx 格式）复制到上述监控文件夹中。
  在控制中心切换到【文件夹扫描】标签页，点击【开始全量扫描】。后台会自动解析文档内容并提炼事实，
  请稍候一至两分钟，待扫描完成后审核页才会出现建议。
第四步【在审核页核准建议】：
  点击左侧导航栏的【待我审核】（或控制中心中的【批量审核】）。
  PAW 已经自动提取出文档中的待办事项、项目进展与知识点。
  查看提议内容，点击卡片下方的【核准并写入】（或在控制中心点击【批量核准入库】）。
第五步【在项目页查看“30秒快速了解”】：
  点击左侧导航栏的【项目】，点击进入对应的项目卡片。
  页面顶部会呈现【30秒读懂这个项目】，清晰列出：
  【一句话读懂】、【当前做到哪里】、【当前最大问题】、【下一步】四大核心事实。
第六步【向 AI 助手提一个问题】：
  点击左侧导航栏的【AI助手】。
  在下方输入框中输入您关心的问题（或点击界面推荐的快捷问题，如“今天有什么需要处理？”、
  “我有哪些正在进行的项目？”），点击【发送】。
  AI 会结合刚才核准的本地知识与项目进展，为您做出清晰完整的解答。

--------------------------------------------------------------------------------
五、常见问题解答 (FAQ)
--------------------------------------------------------------------------------
Q1：提示“端口 8800 已被占用”怎么办？
A1：无需担心，PAW 具备端口自动避让功能。如果 8800 被其他软件占用，PAW 会自动顺延切换至
    8801、8802 等可用端口，浏览器也会自动打开正确的新端口。

Q2：杀毒软件或电脑管家提示拦截怎么办？
A2：PAW 是运行在您个人电脑上的本地软件，由于未向商业机构付费申请数字证书，部分杀毒软件
    可能出现误报。请选择“允许运行”、“信任此应用”或加入信任白名单。

Q3：我的工作数据和文件保存在哪里？
A3：全部数据均保存在您自己的电脑本地，位于系统应用数据目录下：
    %LOCALAPPDATA%\PAW（例如 C:\Users\您的用户名\AppData\Local\PAW）。
    包含本地 SQLite 数据库文件 workspace.db、证据索引与历史备份文件。

Q4：卸载软件后，我的历史数据会丢失吗？
A4：不会。执行卸载程序只会移除软件本体程序和快捷方式，
    %LOCALAPPDATA%\PAW 中的用户数据库与数据快照会被完整保留。重新安装即可继续使用。

Q5：我的办公资料会被上传或泄露吗？
A5：PAW 遵循本地优先原则，所有文档解析、数据库存储和审核流程均在您的电脑本地运行，没有自己的中心服务器。
    数据与外部交互仅有两种明确情形：
    1. 配置大模型 API Key 后：向 AI 助手提问或解析提炼时，必要的上下文片段会发送给您所选择的模型服务商；
    2. AI 助手免 Key 联网搜索：在向 AI 助手提问时，若问题涉及外部时效信息（如包含“最新”、“官网”、“政策”、“新闻”等关键词）或本地知识库中缺乏相关资料，系统会自动向必应（Bing）或 DuckDuckGo 发起网页检索获取参考资料。此时仅发送您输入的提问词，不会将您的本地文档或工作台数据库内容发送出去；如不需要联网搜索，可在提问中加上“只看工作台”或“不要联网”。
