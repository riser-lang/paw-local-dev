================================================================================
                PAW 本地版 v2.5.0 · 第一次使用指南
================================================================================

这份指南带你完成安装、连接模型、导入资料，并查看项目和问答结果。

一、安装与启动
--------------------------------------------------------------------------------
1. 双击安装包，按提示点【下一步】，最后点【完成】。
2. 如果 Windows 显示蓝色安全提示，点【更多信息】→【仍要运行】。
3. 如果安装时提示“无法创建临时文件夹（Error 5）”，右键安装包，选
   【以管理员身份运行】；若安全软件拦截安装，也可先把安装包加入信任。
4. 安装完成后，从桌面或开始菜单打开【PAW Personal Work OS】。工作台会在
   浏览器中打开。开始菜单程序组里的【使用说明】可以再次打开本指南。

二、连接模型（以硅基流动为例）
--------------------------------------------------------------------------------
模型连接后，PAW 才能分析扫描到的文件、生成建议和回答资料问题。请使用自己
有权使用的服务账号，并在 PAW 中自行填写 Key；本说明不包含任何真实 Key。

1. 点击页面左下角的【控制中心】悬浮按钮，打开【PAW 本地控制中心】，进入
   【系统与模型】。
2. 在【推理大脑 Provider 预设模板】选择【自定义 OpenAI 兼容接口 / 网关】。
3. 在【API Key】中填写自己从服务商取得的 Key。
4. 在【Base URL】填写：
   https://api.siliconflow.cn/v1
5. 在【Model Name】填写模型 ID：
   deepseek-ai/DeepSeek-V4.1-Flash
6. 点击【测试当前模型连通性】；连接成功后点【保存所有设置】。

PAW 会把 Key 加密保存在本机。提问或分析时，相关资料片段会发送给你选择的
模型服务商处理。没有填写 Key 时，已有资料仍可查看；需要模型的分析和建议
可能无法生成。

三、导入资料并扫描
--------------------------------------------------------------------------------
1. 打开左下角【PAW 本地控制中心】，在【监控工作目录 (支持添加多个文件夹)】
   点击【添加监控文件夹】，选择存放工作资料的文件夹。
2. 把要导入的文件放进该文件夹。PAW 支持的文件类型会由扫描流程读取。
3. 打开【文件夹扫描】标签页，点击【开始全量扫描】。扫描时每个文件都要经
   模型分析，通常需要几秒到十几秒；文件多、文件大或模型响应慢时会更久。
   页面会显示扫描状态、已处理数量、当前文件和预计剩余时间等进度。
4. 扫描期间可以在面板查看进度；请等扫描结束后再关闭程序。若暂停或中断，
   再次打开扫描面板可按页面提示（【从断点继续扫描】或【继续扫描】）接着
   扫描未完成的文件。

四、工作台主要页面
--------------------------------------------------------------------------------
【驾驶舱】
查看“需要你决定”、项目总览、AI 建议、资料去向和系统状态。甘特图及时间线
根据已有项目资料展示；没有记录的内容不会自动补造。

【项目】与【项目档案】
点击左侧【项目】会直接打开当前项目的档案；还没有项目时先进入项目列表。
档案按栏目展示当前结论、进度、风险、下一步、周报和来源；版本与更新记录中的
【查看来源】可以核对资料依据。AI 生成的说明或建议会标明状态；需要正式写入
的内容仍须经过你的确认。

【资料】
这里保存原始资料索引。扫描导入的文件会出现在列表中。搜索框
【搜索文件名或分类】可以按完整文件名（包括扩展名）或分类筛选。打开资料可
查看系统读取到的正文；部分格式或无法读取的内容可能只保留索引。

【知识】
查看已经沉淀的知识。可以用【搜索正式知识】查找；尚待确认的草稿不会被当作
正式知识。确认来源和内容后，再按页面提示处理。

【待我审核】与【需要你决定】
左侧【待我审核】打开候选审核页，页内的【待确认】列表展示扫描或分析产生的
候选。选中一条后查看原文、来源和影响，再点【拒绝】或【核准并写入】；改动
过草稿要先点【保存草稿】。数据/指标卡缺【标题】或【项目名称】时，点【核准
并写入】会提示“请补充标题和项目名称后再接受”，补齐后才能写入。驾驶舱中的
【需要你决定】展示必须由你决定的项目事项，可逐条选“是”“否”或【稍后】。

【周报】
在项目档案中查看【项目周报】；驾驶舱还会显示【跨项目对比与项目周报】。
周报按已有记录列出进展、变化、风险与冲突、建议及其依据。资料不足的部分
不会被伪装成已确认事实。

【AI助手】
输入问题并发送。回答依据工作台中检索到的资料，来源写在回答末尾的“来源：”
行，引用的知识条目会同时列出原始文件；目前没有单独的“查看来源”面板。例如
询问“如何优化”时，建议内容会标注“建议”，并附上相关来源。资料不足时，助手
会说明依据不足，不应把推测当作已确认事实。

五、常见问题
--------------------------------------------------------------------------------
问：模型连通测试失败怎么办？
答：检查 Key、【Base URL】和【Model Name】是否正确，确认服务账号可用后再
   点击【测试当前模型连通性】。不要把 Key 发给他人或写进公开文档。

问：扫描为什么要等？
答：每个文件都需要读取和模型分析，通常每个文件要几秒到十几秒；资料越多、
   文件越大或服务响应越慢，等待时间越长。请看【文件夹扫描】中的当前文件和
   处理进度。

问：资料已经扫描，但没有出现在知识里？
答：【资料】保存原始资料索引；【知识】显示经过整理并确认的知识，两者用途
   不同。候选在【待我审核】的【待确认】列表处理；项目决策在驾驶舱的
   【需要你决定】中处理。

问：为什么数据/指标卡不能核准并写入？
答：卡片缺【标题】或【项目名称】时会提示“请补充标题和项目名称后再接受”；
   补齐这两项、点【保存草稿】后再点【核准并写入】即可。

问：资料或项目归属不确定怎么办？
答：暂选【稍后】，查看卡片中的依据和“选是 / 选否”后的影响，再补充信息或
   选择正确项目。不确定时不要选“是”。

问：资料会离开本机吗？
答：文件和工作台数据保存在本机。使用模型时，PAW 会把完成当前任务所需的
   资料片段发送给你配置的模型服务商；请勿导入无权处理的敏感资料。

问：在哪里看安装后的这份说明？
答：从开始菜单程序组点击【使用说明】，或在程序安装目录打开【使用说明.txt】。
