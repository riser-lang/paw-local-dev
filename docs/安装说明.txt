========================================================================
             PAW Personal Work OS (Windows 本地化版 v2.3) 安装说明
========================================================================

尊敬的用户：
欢迎使用 PAW Personal Work OS (Windows Desktop Enterprise Edition)！
本软件专为普通办公员工量身打造，无需安装 Python、无需配置复杂环境、无需命令行。

------------------------------------------------------------------------
【第一步：安装运行】
------------------------------------------------------------------------
1. 双击运行安装包：`PAW Setup.exe`；
2. 按照向导提示点击「下一步」，选择安装路径（默认推荐安装在用户目录或 Program Files）；
3. 勾选「创建桌面快捷方式」，点击「安装」；
4. 安装完成后，勾选「立即启动 PAW Personal Work OS」，点击「完成」。

------------------------------------------------------------------------
【第二步：首次启动与引导】
------------------------------------------------------------------------
1. 软件启动后会自动打开您的浏览器并加载工作台页面（默认地址：http://127.0.0.1:8800/app）；
2. 屏幕右下角将自动弹出「PAW 控制中心 - 新手引导」：
   - 步骤一：选择平时保存办公文档的工作文件夹（如 `D:\PAW\工作文档` 或桌面文件夹）；
   - 步骤二：选择 AI 推理服务（推荐选用 DeepSeek 或阿里云通义千问，输入对应的 API Key；若无 Key，可直接选用「纯离线规则推理」）；
   - 步骤三：选择扫描限流模式（默认推荐「标准模式」，安静不卡顿）；
3. 点击「完成引导，开启 PAW 守护」，系统即可正式接管并保护您的工作资产！

------------------------------------------------------------------------
【第三步：日常使用、AI 助手与灾难恢复】
------------------------------------------------------------------------
- 日常办公：像往常一样在工作文件夹内正常编写和保存 Word/Excel/PPT/PDF 即可，PAW 会在后台自动分析；
- 审核中心：打开工作台的「审核」或控制中心的「智能批量审核」，一键核准 AI 提炼的行动待办与知识沉淀；
- AI 个人助理：点击右下角控制中心的「💬 AI 助手 (Agy)」标签页，随时向 PAW 提问项目进度与知识，每条回答附带严密的文件证据定位卡片；
- 安全快照与恢复：在控制中心「⚙️ 系统与模型」页面下方，系统每日自动备份数据库，并支持一键创建快照与一键无损灾难恢复；
- 退出软件：直接关闭后台黑窗口或在系统任务管理器中结束任务即可；
- 重新打开：双击桌面的「PAW Personal Work OS」快捷方式随时唤醒。

------------------------------------------------------------------------
【升级与卸载说明】
------------------------------------------------------------------------
- 覆盖升级：直接运行新版本 `PAW Setup.exe` 安装即可，旧数据库与历史知识库将无缝保留；
- 软件卸载：在 Windows「设置」->「应用」中找到「PAW Personal Work OS」点击卸载；
  卸载向导会明确提示「是否同时删除本地用户数据与知识库？」，默认点击「否」即可安全保留您所有珍贵的历史工作资产。
