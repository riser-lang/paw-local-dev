========================================================================
             PAW Personal Work OS (Windows 本地化版 v2.5.0) 安装说明
========================================================================

尊敬的用户：
欢迎使用 PAW Personal Work OS (Windows Desktop Enterprise Edition)！
本软件专为普通办公员工量身打造，无需安装 Python、无需配置复杂环境、无需命令行。

------------------------------------------------------------------------
【第一步：安装运行】
------------------------------------------------------------------------
1. 双击运行安装包：`PAW_Personal_Work_OS_Setup_v2.5.0.exe`；
2. 按照向导提示点击「下一步」，选择安装路径（默认推荐安装在用户目录或 Program Files）；
3. 勾选「创建桌面快捷方式」，点击「安装」；
4. 安装完成后，勾选「立即启动 PAW Personal Work OS」，点击「完成」。

------------------------------------------------------------------------
【第二步：首次启动与引导】
------------------------------------------------------------------------
1. 软件启动后会自动打开您的浏览器并加载工作台页面（默认地址：http://127.0.0.1:8800/app）；
2. 首次启动会自动打开【PAW 本地控制中心】的「引导」页：
   - 步骤一：选择平时保存办公文档的工作文件夹（如 `D:\PAW\工作文档` 或桌面文件夹）；
   - 步骤二：选择 AI 模型服务（模板有 DeepSeek、通义千问 Qwen、OpenAI、自定义 OpenAI 兼容接口；填入自己的 API Key。没有 Key 时可选「纯离线规则推理」）；
   - 步骤三：选择资源限流模式（默认推荐「标准模式」，办公时不卡顿）；
3. 点击「完成引导，开启 PAW 守护」，系统即可正式接管并保护您的工作资产！

------------------------------------------------------------------------
【第三步：日常使用、AI 助手与灾难恢复】
------------------------------------------------------------------------
- 日常办公：像往常一样在工作文件夹内正常编写和保存 Word/Excel/PPT/PDF 即可，PAW 会在后台自动分析；
- 审核中心：打开工作台的【待我审核】，或控制中心的「批量审核」标签页，一键核准 AI 提炼的行动待办与知识沉淀；
- AI 个人助理：点击左侧【AI助手】，随时向 PAW 提问项目进度与知识；回答末尾的「来源：」行会列出依据的资料，引用的知识条目还会写出原始文件名；
- 安全快照与恢复：在控制中心「系统与模型」页面下方有「数据库自动备份与灾难恢复」，系统每日自动备份数据库；可点「+ 立即创建安全快照」，需要还原时在备份清单里点「恢复」；
- 退出软件：关闭浏览器页面不会退出程序；需要退出时，在任务管理器中结束「PAW_Personal_Work_OS.exe」进程；
- 重新打开：双击桌面的「PAW Personal Work OS」快捷方式随时唤醒。

------------------------------------------------------------------------
【升级与卸载说明】
------------------------------------------------------------------------
- 覆盖升级：直接运行新版本 `PAW_Personal_Work_OS_Setup_v2.5.0.exe` 安装即可，旧数据库与历史知识库将无缝保留；
- 软件卸载：在 Windows「设置」->「应用」中找到「PAW Personal Work OS」点击卸载；
  卸载向导会询问「是否同时删除 PAW 工作数据？」，默认按钮是「否」，点「否」即可安全保留您所有珍贵的历史工作资产。
