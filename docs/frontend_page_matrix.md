# PAW Personal Work OS 前端逐页对照表 (v2.2)

> 依据《PAW Personal Work OS 本地化 Windows 版 开发任务书 v2.2》第 5.2 节要求编制。
> 对照云端实际部署代码与本地版处理方式，逐页逐项进行功能与架构对齐。

| 页面 / 路由 | 云端现状 (Cloud) | 本地版处理 (Local) | 处理原因与本地化调整说明 |
|:---|:---|:---|:---|
| **今日工作看板<br>(`/today`, `/daily`)** | 显示今日指标卡片、近期待办、活跃项目摘要与每日汇总。从 `/v1/web/workspace/daily` 聚合获取。 | **原样保留** | 核心信息架构完全一致。本地版通过本地 SQLite 数据库查询，毫秒级响应，视觉与交互 100% 保持原生。 |
| **项目工作台<br>(`/projects`)** | 展示项目卡片流、状态/阶段过滤器、项目详情抽屉、关联知识与产出物。 | **原样保留** | 核心项目台账管理逻辑不变，直接对接本地 41 表的 `project` 与 `project_handbook`，免去网络延迟。 |
| **知识资产库<br>(`/knowledge`)** | 知识卡片网格、类型标签筛选（方法/规则/分析/项目/领域）、一句话摘要与修订历史版本。 | **原样保留** | 保留云端全部 650+ 篇知识资产与查看能力，支持腾讯乐享细分类目映射。 |
| **行动待办<br>(`/todos`)** | 待办任务清单、完成勾选、按项目归集、优先级标记。 | **原样保留** | 用户勾选待办完成时直接经 Committer 事务原子落库，确保本地一致性。 |
| **审核中心<br>(`/review`)** | 待审提案列表、影响实体卡片、高保真证据定位符（Locators）、一键通过/驳回。 | **保留并深度增强** | **保留原有审批流**；针对首次扫描产生数百上千条候选的痛点，新增：<br>1. **按项目/置信度智能分组**<br>2. **批量通过/批量驳回**（必须经用户明确点击）<br>3. 显式标注 `[AI提炼]` 或 `[规则提炼·离线]`，杜绝静默降级假装 AI。 |
| **本地源文件<br>(`/files`, `/sources`)** | 云端为只读文件列表或上传组件。 | **修改为本地文件适配** | 本地无需上传按钮，直接映射本地监控工作目录（`data/sources`），显示已捕获文件、大小、哈希与解析状态。 |
| **首次引导向导<br>(Onboarding)** | 云端无此流程（依赖短信验证码/密码注册登录）。 | **本地版新增** | **面向零基础同事**：欢迎介绍 → 选择本地工作文件夹 → **预扫描确认**（告知文件数与预估时间）→ 配置模型并**测试连接** → 设定巡航模式，全流程支持上一步回退与中文人话提示。 |
| **巡航与扫描控制面板<br>(Cruise Control)** | 云端由后台 systemd 定时任务静默拉起，用户无感知也无法干预。 | **本地版新增** | **赋予用户完全掌控权**：<br>1. 显示总文件数、已处理数、当前文件名、已用时间、**预计剩余时间 (ETA)**<br>2. 支持**暂停 / 继续 / 停止**（暂停真实释放 CPU/内存）<br>3. 支持**断点续扫**（中途关闭重启不重复解析已处理文件）<br>4. 支持资源限流调节（安静 / 标准 / 全速）。 |
| **失败清单页<br>(Failed Files)** | 云端仅记录后端日式 `tc.log`，无前端界面，普通用户无法查看。 | **本地版新增** | 遇到损坏/加密/占用/超大文件时**一律跳过记入失败清单，禁止弹窗打断**。清晰显示：文件路径、**人话失败原因**、建议处理方式以及“单个重试”按钮。 |
| **首次扫描摘要页<br>(Scan Summary)** | 云端无（云端为运维批量预导入）。 | **本地版新增** | 首次全量扫描完成后呈现一页全局摘要：“共处理 N 个文件，发现 X 个项目线索、Y 条知识、Z 条待办，建议优先处理高置信度候选”。 |
| **模型 Provider 设置页<br>(Model Settings)** | 云端固定为服务端写死的环境变量，前端无法自选。 | **本地版新增** | 统一 OpenAI 协议兼容客户端接入（支持 DeepSeek / 通义千问 / OpenAI / 自定义预设模板），**API Key 使用 Windows DPAPI 加密存储且不回显**，提供真实“测试连接”探针。 |
| **系统医生面板<br>(Doctor Diagnosis)** | 云端为命令行 Python 探针脚本 `_proc_check.py`。 | **本地版新增可视面板** | 面向非技术人员的可视化健康体检：数据库、Reader 逆向引擎、模型连接、磁盘空间、端口占用、目录权限，每项给出“是否正常 + 怎么办”。 |
| **Evolution Engine 演进面板<br>(Evolution Dashboard)** | 云端无。 | **本地版新增** | 呈现知识健康仪表盘（新鲜度、孤立知识检测）、跨实体上下文图谱（Context Graph）与项目长期记忆（Project Memory）。 |
